# v0.1 full QLoRA validation run

## Purpose and scope

This is the first full supervised fine-tuning run for MURL. It compares a
60-step QLoRA adapter with the untouched base model under the same SFT system
prompt on the 48-example validation split. The held-out test split was not
read or used.

## Configuration and training

| Item | Value |
| --- | --- |
| Source configuration | `configs/qlora-v0.1-full.yaml` at repository commit `86cadf5` |
| Base model | `Qwen/Qwen2.5-3B-Instruct` at `aa8e72537993ba99e69dfaafa59ed015b17504d1` |
| Training data | 155 conversations; SHA-256 `16365760e906c0fe48c3c1d1b15ecb281e2c374bdacdf1f2cae60996edfa9aac` |
| QLoRA | 4-bit NF4; rank 8; alpha 16; dropout 0.05; float16 on Tesla T4 |
| Training | 60 optimizer steps; batch size 1; gradient accumulation 8; learning rate `2e-4`; 3 warmup steps |
| Training result | 3.0 epochs; loss 0.5617; 432.0 seconds |
| Adapter reload | Passed |
| Evaluation | Validation only; greedy decoding; maximum 256 new tokens |

The base control and adapter used the same system prompt and the same 48
validation examples. Their only intended difference was the adapter.

## Validation result

| Metric | Untouched base control | Full QLoRA adapter |
| --- | ---: | ---: |
| Valid structured outputs | 0/48 (0.0%) | 48/48 (100.0%) |
| Correctness accuracy, valid outputs only | Not available | 58.3% |
| Correctness macro F1, valid outputs only | Not available | 43.7% |
| Taxonomy macro F1, valid outputs only | Not available | 31.7% |
| First-error exact match, valid outputs only | Not available | 51.7% (15/29) |
| First-error mean absolute distance, valid outputs only | Not available | 0.48 steps |

The base model responded in a human-readable but incompatible label format,
such as `Partially Correct` and `Calculation Error`, so none of its responses
met the benchmark schema. Its classification and localization metrics therefore
cannot be computed; the zero is a format failure, not a score of zero task
quality. The adapter reliably learned the required canonical JSON and labels.

The adapter's strongest result here is structured-output reliability. Its
correctness and taxonomy quality still need qualitative review before making a
new training decision. This validation result is not comparable to the held-out
few-shot baseline because the prompt and split differ.
