# v0.3 taxonomy-guidance QLoRA validation run

## Purpose and scope

This run retains v0.2 correctness-label guidance and adds concise taxonomy
decision rules for the validation confusions found in v0.2. It compares the
adapter with an untouched base-model control under the same v0.3 prompt on the
48-example validation split. The held-out test split was not read or used.

## Validation comparison

| Metric | v0.1 full | v0.2 label guidance | v0.3 taxonomy guidance |
| --- | ---: | ---: | ---: |
| Valid structured outputs | 100.0% (48/48) | 97.9% (47/48) | 97.9% (47/48) |
| Correctness accuracy, valid outputs only | 58.3% | 66.0% | 72.3% |
| Correctness macro F1, valid outputs only | 43.7% | 49.3% | 53.0% |
| Taxonomy macro F1, valid outputs only | 31.7% | 20.7% | 19.7% |
| First-error exact match, valid outputs only | 51.7% (15/29) | 53.6% (15/28) | 50.0% (14/28) |
| First-error mean absolute distance, valid outputs only | 0.48 steps | 0.42 steps | 0.41 steps |

v0.3 has the best correctness metrics, but it does not solve the taxonomy
regression and slightly lowers exact first-error localization. The matching
untouched base control again produced no schema-valid outputs, so its task
metrics are unavailable.

## Decision

Do not make another prompt-only adjustment. The prompt is already explicit,
yet the taxonomy metric decreased in both v0.2 and v0.3. The next experiment
should retain v0.2's correctness guidance and use a training-only,
taxonomy-balanced sampling strategy. That tests a different cause of the
regression without reading validation or test examples.

No version is selected for the held-out test set yet. Before cross-model
testing, establish whether a data-balance intervention can improve taxonomy
without sacrificing v0.3's correctness gains.
