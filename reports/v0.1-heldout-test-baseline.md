# v0.1 held-out few-shot baseline

## Scope

This is the single held-out evaluation selected in
[the prompt-selection record](v0.1-prompt-selection.md). The test split was not
used to select the prompt. No further prompt changes or test reruns should be
made for this baseline comparison.

## Failure review and interpretation

Seven outputs were invalid. Five contained LaTeX backslashes that were not
JSON-escaped. One used an unsupported taxonomy label, and one violated the
first-error/taxonomy contract. Among the 40 valid outputs, the model correctly
recognized 19 `correct` examples, but marked 7 `incorrect` and 6 `minor_error`
examples as `correct`. It correctly predicted taxonomy for 21 of 40 valid
outputs.

The configuration is therefore a reproducible prompt-only baseline for a
grader-assistance experiment, not a reliable grading model. The next experiment
should target structured-output reliability and detection of local mathematical
errors through supervised QLoRA/SFT training on the training split only.
