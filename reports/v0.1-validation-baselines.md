# v0.1 validation prompt baselines

## Scope

This report compares zero-shot and few-shot prompting for structured grading of worked integration solutions. It covers the frozen validation split only. The test split was not read or evaluated.

## Prompt and smoke-test history

The original zero-shot prompt placed pipe-separated label menus directly in the JSON example. In a 10-example smoke test, six responses copied the menu into `overall_correctness`, leaving 4/10 schema-valid outputs. The prompt now uses a concrete JSON example and explicitly prohibits copied or combined labels. A second 10-example smoke test reached 8/10 valid outputs. The full runs below use the corrected prompts.

## Results

| Run | Valid outputs | Correctness accuracy* | Correctness macro F1* | Taxonomy macro F1* | First-error exact match* | First-error mean absolute distance* |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Zero-shot | 45/48 (93.8%) | 28.9% | 18.7% | 9.2% | 42.9% | 0.40 |
| Few-shot | 45/48 (93.8%) | 51.1% | 29.1% | 16.9% | 19.2% | 0.29 |

*Classification and localization metrics are computed only on schema-valid outputs. Three outputs in each run were invalid; no examples were missing, duplicated, or unexpected.

Few-shot improves validation correctness accuracy by 22.2 percentage points and taxonomy macro F1 by 7.7 points. Its first-error exact match is lower, while its mean distance is smaller on the examples it localizes. These results select few-shot as the prompt to inspect further; they do not justify using the test split yet.

## Next decision

Review representative few-shot successes and failures, especially malformed JSON, incorrect taxonomy labels, and first-error disagreements. Add stratified metrics by topic, difficulty, and taxonomy before freezing the prompt. Once the selection rule is written down, run the chosen configuration once on the held-out test split. Then prepare supervised training conversations from the training split for the first QLoRA/SFT experiment.
