# v0.1 QLoRA smoke run

## Purpose and scope

This was a 10-step infrastructure smoke run, not a tuned adaptation experiment.
It trained only on the 155-record SFT training file, saved an adapter, reloaded
that adapter successfully, and evaluated it once on validation. The test split
was not read or used.

## Configuration and training check

| Item | Value |
| --- | --- |
| Base model | `Qwen/Qwen2.5-3B-Instruct` at `aa8e72537993ba99e69dfaafa59ed015b17504d1` |
| Training data | 155 conversations; SHA-256 `16365760e906c0fe48c3c1d1b15ecb281e2c374bdacdf1f2cae60996edfa9aac` |
| QLoRA | 4-bit NF4; rank 8; alpha 16; dropout 0.05; float16 on Tesla T4 |
| Training | 10 optimizer steps; batch size 1; gradient accumulation 8; learning rate `2e-4` |
| Training loss | 1.2001 |
| Training runtime | 69.9 seconds |
| Adapter reload | Passed |

## Validation smoke result

| Metric | Result |
| --- | ---: |
| Valid outputs | 32/48 (66.7%) |
| Correctness accuracy, valid outputs only | 53.1% |
| Correctness macro F1, valid outputs only | 22.6% |
| Taxonomy macro F1, valid outputs only | 7.1% |
| First-error exact match, valid outputs only | 0.0% (0/15) |

The checkpoint runs and the evaluator consumes its outputs, which is the smoke
run's success criterion. Its metrics are not a fair comparison to the prompt
baseline: it trained for only 10 steps and uses the SFT system prompt instead of
the few-shot prompt. The low validity and zero first-error exact matches show
that it is not ready for held-out evaluation.

## Saved local artifacts

- `runs/baseline/qlora-smoke-validation-results.zip` — validation inputs, raw

- `runs/baseline/qlora-smoke-execution.ipynb` — exported Colab execution log.

The T4 session was stopped after downloading these artifacts.

## Next decision

Create a matching zero-training-step base-model control under the SFT system
prompt, inspect the smoke run's malformed validation outputs, then train one
longer, versioned adapter on the training split. Compare that adapter and its
matching base control on validation only. The held-out test split remains frozen.
