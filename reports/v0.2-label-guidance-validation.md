# v0.2 label-guidance QLoRA validation run

## Purpose and scope

This run tests whether giving the model the benchmark's exact correctness and
taxonomy definitions improves the full v0.1 QLoRA adapter. It compares the
adapter with an untouched base-model control under the same v0.2 prompt on the
48-example validation split. The held-out test split was not read or used.

## Validation comparison

| Metric | v0.1 full adapter | v0.2 label-guidance adapter |
| --- | ---: | ---: |
| Valid structured outputs | 48/48 (100.0%) | 47/48 (97.9%) |
| Correctness accuracy, valid outputs only | 58.3% | 66.0% |
| Correctness macro F1, valid outputs only | 43.7% | 49.3% |
| Taxonomy macro F1, valid outputs only | 31.7% | 20.7% |
| First-error exact match, valid outputs only | 51.7% (15/29) | 53.6% (15/28) |
| First-error mean absolute distance, valid outputs only | 0.48 steps | 0.42 steps |

The v0.2 control again produced no schema-valid outputs, so its task metrics
are unavailable. The adapter remains necessary for the output contract.

The label guidance worked for the primary observed error: it changed several
material errors from `minor_error` to `incorrect`, raising correctness
accuracy and macro F1. It did not improve taxonomy selection. In particular,
v0.2 more often confused algebra with antiderivative, sign with substitution,
and bounds with other. One response used an unrecognized taxonomy value, which
caused the only invalid output.

This is a mixed result, not a final-model selection. It improves correctness
and localization slightly but regresses on taxonomy and validity. The next
iteration should target taxonomy calibration specifically while preserving the
v0.2 correctness guidance. The held-out test remains frozen.
